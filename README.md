# IxKits — Kit Creation Studio

**Plugin de Minecraft desarrollado por CS Studios.**

IxKits es una herramienta administrativa con una GUI de inventario para crear, editar y preparar kits para otros plugins. No añade un sistema de reclamación de kits para jugadores.

- **Código del plugin:** [IxKits](./IxKits/)
- **Compilación automática:** [GitHub Actions](./actions)
- **Guía del plugin:** [IxKits/README.md](./IxKits/README.md)
- **Entorno de compilación:** Java 21 + Gradle 8.10.2
- **Salida esperada:** `IxKits/build/libs/IxKits-0.1.0.jar`

Para descargar el JAR, abre **Actions → Build IxKits → la ejecución correcta más reciente → Artifacts → IxKits-JAR**.

El catálogo comunitario online todavía requiere una API y almacenamiento web; no está activo en esta versión.
