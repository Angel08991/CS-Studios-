Conectar el backend

Configura la base de datos online para que el marketplace sea compartido.

Necesario para funciones online. Crea un proyecto Supabase, ejecuta la migración SQL incluida en el ZIP y pega la URL del proyecto y su clave pública (anon/publishable). Nunca pegues aquí la service_role key ni una clave secreta.

Estos datos se guardan en este teléfono. La clave pública está pensada para el cliente y las políticas RLS son las que protegen los datos.

Pasos de configuración
  1. Crea un proyecto en Supabase.
  2. Ejecuta supabase/migrations/001_marketplace.sql en SQL Editor.
  3. Copia la URL y la clave pública desde Project Settings → API.
  4. Conecta aquí e inicia sesión con tu correo.
  5. Despliega las Edge Functions desde la carpeta supabase/functions para habilitar pagos premium.
No almacenes claves secretas de backend en la app.
